# BirdieBuddies

Golf Sticks skins scorecard (R/G/Joker team draw, handicap strokes, tie carryover multipliers) with a satellite course map.

- Course search via [OpenGolfAPI](https://api.opengolfapi.org) (name or GPS radius, worldwide incl. Korea)
- 🗺 Course map (Leaflet + Esri World Imagery / OpenStreetMap): live GPS, long-press to pin each hole's green, distance to green / target in yd and m
- Single `index.html`, no build step; data stays in the browser (localStorage)
